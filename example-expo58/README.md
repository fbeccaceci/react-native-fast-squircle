# Expo SDK 58 example

This app uses Expo SDK 58 and React Native 0.88. The Yarn workspace links
`react-native-fast-squircle` to the library in this repository. Metro loads the
library from `src/`. Native builds use the local `android/` and `ios/` code.

Use Node.js 22.13+, 24.3+, or 26+. The root `.nvmrc` selects Node.js 20,
which does not meet the Expo SDK 58 requirement.

Run these commands from the repository root:

```sh
yarn install
yarn example-expo58 android
```

The Android command creates the native project, builds the app, and starts it on
an Android device or emulator. Use a native build because Expo Go does not contain
this library.

To build a debug APK without a device:

```sh
yarn example-expo58 build:android
```

The APK is at `example-expo58/android/app/build/outputs/apk/debug/app-debug.apk`.
Install the Android SDK and Java version required by Expo SDK 58 before the build.
Set `ANDROID_HOME` to the Android SDK path.

To start Metro for an installed app:

```sh
yarn example-expo58 start
```

To build for iOS:

```sh
yarn example-expo58 ios
```

Changes to JavaScript use Fast Refresh. Build the app again after native code
changes. The native projects are generated by Expo and are ignored by Git.

To check the app types:

```sh
yarn example-expo58 typecheck
```
